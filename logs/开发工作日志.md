# 微信消息朗读助手开发工作日志

## 当前最终目标

本软件目标简单明确：稳定朗读电脑版微信当前个人聊天或群聊里的新文字消息正文。

当前范围：

1. 朗读微信好友聊天的新文字消息。
2. 朗读微信群聊里的新文字消息。
3. 只朗读文字正文。
4. 语音、图片、文件、转账、表情等非文字内容暂不处理。
5. 保持无障碍友好：支持键盘操作，状态和通知记录可复制，按钮和控件名称尽量适合读屏读取。

## 当前主要功能

1. WPF 桌面软件，支持绿色版发布。
2. 打开软件后自动开始监控微信当前聊天。
3. 如果微信没打开，或微信刚关闭后正在重新打开，软件会等待微信稳定后再读取，避免在微信启动阶段强行扫描导致微信卡死。
4. 默认使用 UI Automation 读取当前微信聊天窗口里的文字消息。
5. 第一次读取到的当前可见消息会临时视为旧消息，避免打开软件后立即朗读一堆旧内容。
6. 后续只朗读新出现的文字消息正文。
7. 支持已朗读历史文件，减少重复朗读：`D:\WeChatMessageReaderAssistant\config\wechat-read-history.json`。
8. 支持快捷键：
   - `Alt+R`：测试朗读。
   - `Alt+S`：停止朗读。
   - `Control`：打断当前朗读。
   - `Alt+M`：开始或停止监控当前微信聊天。
   - `Alt+W`：微信 UIA 诊断。
   - `Alt+B`：MSAA/IAccessible 诊断。
9. 支持朗读引擎选择和保存：自动选择、NVDA、争渡、Windows SAPI、Windows OneCore。默认优先争渡。
10. 通知记录、当前状态、诊断信息都可以复制。

6. 手动 `Alt+M` 仍然可用：可以停止监控，再按一次重新开始监控。
